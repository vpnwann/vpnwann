## 👨‍💻 About Me

I'm a **Full-Stack Engineer focused on the JavaScript ecosystem**, building modern web and mobile applications while working across backend systems, servers, networking, cloud infrastructure, and DevOps.

I enjoy understanding the complete lifecycle of a product — from designing the UI and writing APIs to configuring servers, deploying containers, managing infrastructure, and keeping production systems reliable.

My primary ecosystem is:

**JavaScript → React → Next.js → React Native → Node.js → Databases → Redis → Docker → Cloud → DevOps**

- 🔭 Building **full-stack web & mobile applications**
- ⚛️ Developing modern interfaces with **React & Next.js**
- 📱 Building cross-platform applications with **React Native**
- ⚙️ Designing backend systems with **Node.js**
- 🗄️ Working with **MongoDB, PostgreSQL & Redis**
- 🐳 Containerizing and deploying applications with **Docker**
- ☁️ Working with **cloud infrastructure and production deployments**
- 🌐 Exploring **networking, Linux servers & infrastructure**
- 🔄 Building **CI/CD and automated deployment workflows**
- 🧠 Deepening my knowledge of **system design & distributed systems**
- 🤝 Open to **Open Source and interesting engineering projects**
